# 運行管理シミュレーター（総合指令）

JR関西エリアの実時刻表で列車を運行させる、ブラウザ完結の運行管理シミュレーターです。
実際の運行管理システム（CTC／PRC）の画面構成を模しています。

- 全50線区を同時に運行し、全線概況ボードで各線の遅延状況を一覧
- CTC風の運行図: 区間の在線表示（赤）、信号表示、列車番号＋遅延表示
- 遅延は後続列車へ波及（最小運転時隔による簡易閉塞モデル＋回復運転）
- 指令操作: 抑止 / 車両点検 / 次区間徐行 / 区間徐行設定 / 運転打ち切り / 運休 / 緊急停止（全線）
- 警報パネル（5分・10分以上の遅延、運休、抑止、緊急停止）
- 選択列車の着発実績テーブル、ダイヤグラム（実績）、運行実績CSV出力
- 実時刻同期、速度 ×1 / ×10 / ×60 / ×300、ランダムトラブル自動発生

公開ページにはデモ路線（架空）のダイヤが入っています。
手元の実時刻表データ（sim_data_*.json）は「時刻表JSONを読込」から読み込めます（データはブラウザ内でのみ処理され、送信されません）。

出典: JRおでかけネット公式時刻表（JR西日本）。実時刻表データは交通新聞社「JR時刻表」準拠のため、本リポジトリには含めていません。
